MyDealz Design System

docs/design/DESIGN-mydealz.md

Core Philosophy

High-density German deals-community system built on a confident brand green, stacked white cards with signature hot/cold temperature vote meters, and 540px pill buttons.

Palette Tokens

Typography Stack

Display / Heading: Averta CY / Inter (Weight: 700)
Body: Averta CY / Inter (Weight: 500, 15px)
Eyebrows & Code: JetBrains Mono

Geometry & Elevation

Border Radii: 540px Pills (Buttons & Meters), 10px Cards
Elevation: Minimal, subtle hairline borders (#dfe1e4)
Key UI Tell: Hot/Cold temperature meters (+842°)

Suitability for AlongSide Sanctuary

Strengths: Extremely high information density, clear scannable milestones, engaging community verification feel.
Trade-offs: Needs careful calibration so the clinical advisory doesn't feel like an e-commerce coupon forum.
