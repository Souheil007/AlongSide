## 1. Executive Architecture

The `docs/research/` directory houses the canonical scientific, clinical, and pedagogical foundations of the AlongSide platform. 
To power the **Parent Intelligence Academy**, the **24/7 AI Child Advisor**, the **Milestone Tracker**, and the **Bilateral Family Agreement Engine**, this vault organizes primary clinical documents, behavioral scripts, pediatric triage guidelines, milestone trackers, digital media science, and master video lectures across all **8 canonical lifespan developmental tiers (Ages 0 to 18)**.

```
ALONGSIDE LIFESPAN DEVELOPMENTAL TIERS (AGES 0 TO 18):
┌───────────┬──────────────────────────────────┬──────────────┬────────────────────────────────────────────────────────┐
│ Tier      │ Developmental Cohort             │ Age Range    │ Core Biological & Behavioral Focus                     │
├───────────┼──────────────────────────────────┼──────────────┼────────────────────────────────────────────────────────┤
│ **0A**    │ Infancy                          │ 0–12 Months  │ Somatic Regulation, Sleep Architecture & Feeding       │
│ **0B**    │ Young Toddler                    │ 12–24 Months │ Locomotion, Receptive/Expressive Gap & Co-Regulation   │
│ **0C**    │ Older Toddler                    │ 24–36 Months │ Autonomy vs Shame, Potty Learning & Boundary Testing   │
│ **1**     │ Early Childhood & Preschool      │ Ages 4–6     │ Theory of Mind, Cooperative Rules & Screen Intro       │
│ **2**     │ Middle Childhood                 │ Ages 7–9     │ Adrenarche Hormonal Awakening, Concrete Logic & Sports │
│ **3**     │ Pre-Teen & Tweens                │ Ages 10–12   │ Gonadarche, Social Brain dACC Pain & Group Chats       │
│ **4**     │ Early Adolescence                │ Ages 13–15   │ Peak Puberty, +2h Circadian Shift & Digital Amnesties  │
│ **5**     │ Late Adolescence / Launch        │ Ages 16–18+  │ Executive Prefrontal Maturation & Digital Sovereignty  │
└───────────┴──────────────────────────────────┴──────────────┴────────────────────────────────────────────────────────┘
```

## 2. Canonical Tier Research Folders & Core Document Schema

Every tier directory contains 6 unabridged, clinical-grade primary research documents:

```
TIER FOLDER DIRECTORY STRUCTURE:
docs/research/<tier-name>/
├── 01-clinical-neurobiology-and-development.md   # Structural brain anatomy, hormones, sleep architecture, red flags
├── 02-behavioral-psychology-and-dialogue-scripts.md# De-escalation science, comparative dialogue tables, action protocols
├── 03-pediatric-health-nutrition-and-routines.md   # Feeding science, pediatric acute triage, daily schedules
├── 04-milestones-brain-play-and-enrichment.md      # CDC/AAP 2022 milestones, brain games, stage-appropriate materials
├── 05-digital-boundaries-culture-and-pacts.md      # Screen science, dopamine dynamics, Bilateral Pact clauses
└── 06-video-multimedia-curriculum-and-lectures.md  # Curated master lectures, TED talks, YouTube URLs & lesson integration
```

## 3. Platform Knowledge Base Integration

The 48 core research documents across these 8 tier directories serve as the primary knowledge ground truth for:
1. **The Parent Intelligence Academy:** Directly providing the clinical theory, scripts, and video curriculum for each course lesson.
2. **The 24/7 AI Child Advisor:** Serving as primary RAG retrieval chunks in PostgreSQL 16 `pgvector` to generate age-tailored, empathetic, non-punitive parenting guidance.
3. **The Lifespan Milestone Tracker:** Fueling the 75th percentile AAP/CDC motor, speech, and cognitive checkpoints in `packages/database/prisma/seed/milestones.seed.ts`.
4. **The Bilateral Family Pact Engine:** Providing the exact age-appropriate legal and digital clauses compiled into Apple `.mobileconfig` profiles and Android MDM policies.
