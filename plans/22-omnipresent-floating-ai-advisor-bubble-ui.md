## 1. Objective & Business Value

Transform the 24/7 AI Child Advisor from a siloed, isolated tab into a ubiquitous, frictionless floating companion accessible across the entire AlongSide family operating system.

Currently, if a parent is reviewing 2:00 AM pediatric fever guidelines in `/health`, reading an allergen introduction timeline in `/nutrition`, or reviewing a tantrum de-escalation protocol in `/behavior`, they must navigate completely away from that page to ask the AI advisor a question. 

This plan implements the **Hybrid AI Advisor Architecture**:
1. **Global Omnipresent Floating Advisor Bubble (`FloatingAdvisorBubble.tsx`):** A discreet, calming floating action button (FAB) mounted in the application shell that slides open an interactive chat drawer from anywhere in the app.
2. **Context-Aware Situational Prompts:** The bubble automatically detects the currently selected child (name, age, developmental tier) and the current route, generating instant 1-tap questions (e.g. fever dosage queries on `/health`, fussy eating scripts on `/nutrition`, boundary phrases on `/devices`).
3. **Seamless Transition to Deep Rehearsal Studio:** The drawer includes a prominent 1-tap link to `/advisor` for parents who want to enter the full-screen Voice Sparring Simulator or browse the 250+ Clinical FAQ Vault.

## 4. Step-by-Step Implementation Tasks

### Task 1: Contextual Prompt Resolver (`apps/web/src/lib/advisor-context.ts`)
1. Create a pure utility function that generates 3–4 tailored quick prompts based on:
   - `pathname: string` (e.g. `/health`, `/nutrition`, `/brain-games`, `/behavior`, `/devices`, `/dashboard`)
   - `child: ChildDTO | null` (name, age, developmental tier)
2. Prompt generation matrix:
   - **`/health`**:
     * *"[Child] has a 101.5°F fever — when should I call the doctor?"*
     * *"What are safe non-medicinal ways to help [Child] sleep with a cough?"*
   - **`/nutrition`**:
     * *"How do I safely introduce thinned peanut butter to [Child]?"*
     * *"What should I do when [Child] refuses to eat anything green at dinner?"*
   - **`/behavior`**:
     * *"Give me a 3-sentence de-escalation script for [Child]'s screaming meltdown."*
     * *"How to handle bedtime stalling without yelling."*
   - **`/devices`**:
     * *"Is [Child] ready for an Apple Watch or phone?"*
     * *"What does 'crashout' mean in tween slang?"*
   - **`/dashboard` or default**:
     * *"What is the most important milestone for a [Age]-year-old right now?"*
     * *"Quick 5-minute boredom buster game I can play with [Child] today."*

### Task 2: Floating Advisor Bubble & Slide-Over Drawer (`apps/web/src/components/advisor/FloatingAdvisorBubble.tsx`)
1. Build `FloatingAdvisorBubble.tsx`:
   - Position: Fixed at `bottom-6 right-6` (desktop) and `bottom-20 right-4` (mobile, sitting above `MobileNav`).
   - State: Collapsed bubble vs. Expanded slide-over drawer / modal.
   - Design:
     * High-contrast, calming teal bubble with shield/bot icon and subtle pulse glow when idle.
     * Accessible tooltip / label: "Ask Alongside AI Advisor".
     * Close button (`X`), minimize button, and "Open Full Rehearsal Studio" link targeting `/advisor`.
2. Drawer Contents:
   - **Header:** Displays AlongSide AI Advisor badge, active child indicator (e.g. *"Advising for Mateo, 14 mo"*), and link to `/advisor`.
   - **Quick Action Pills:** Horizontally scrollable chips generated by `resolveContextualPrompts()`. Tapping a chip immediately sends the message.
   - **Compact Message Feed:** Scrollable chat history reusing `useAiAdvisorChat` with live SSE token streaming, markdown rendering, and empathetic clinical voice.
   - **Input Bar:** Auto-resizing textarea with Enter-to-send, voice mode shortcut, and stop-streaming button.

### Task 3: Global Layout Integration (`apps/web/src/app/(dashboard)/layout.tsx`)
1. Mount `<FloatingAdvisorBubble />` in `apps/web/src/app/(dashboard)/layout.tsx`.
2. Ensure the drawer renders inside a React Portal or fixed z-index (`z-50`) to guarantee it floats over all page elements without layout shifting.
3. Test keyboard accessibility: `Escape` key closes the drawer; focus is trapped within the drawer while open.

### Task 4: Deep Rehearsal Studio Synergy (`apps/web/src/app/(dashboard)/advisor/page.tsx`)
1. Ensure the dedicated `/advisor` route remains the primary hub for:
   - Low-latency Voice Sparring Simulator (Web Audio microphone input, roleplaying an upset child, real-time feedback).
   - Full 250+ FAQ Vault search with developmental category filters.
2. In the floating drawer, clicking "Open Full Rehearsal Studio" transitions seamlessly to `/advisor` while preserving conversation context in `useAiAdvisorChat`.
